# Documentation index

**Start here**
* `../README.md` (English) and `../README.pt-BR.md` (Portuguese): what the repository contains, the three levels of use
  and the quick start.
* `tutorial/README.md`: the tutorial, 13 chapters from the MEGAN equations to the map of every number.
* `../TUTORIAL_MEGAN_SC_pt.pdf`, `../TUTORIAL_MEGAN_SC_en.pdf`: the illustrated tutorial (sources in `tutorial/`).
* `../REPRODUCE.md`: the short version of tutorial chapters 5 and 6.

**Reference**
* `ALGORITHM_SPEC.md`: MEGANv3.21 equations and constants as transcribed from the Fortran source, with the input and
  run procedures of `fixes.py` (FIX-1 to FIX-8) and the settings of the Santa Catarina run (section 11).
* `TIME_CONVENTIONS.md`: time reference of each input (UTC, instantaneous and accumulated fields, composites), how the
  model uses time (solar position in local mean solar time, daily mean temperature, UTC months) and what each does to
  the results.
* `../VALIDATION.md`: comparison with the official Fortran, checks of the production run, TROPOMI evaluation,
  sensitivity tests and reproduction.
* `../DATA_AVAILABILITY.md` and `../data/README.md`: sources, licences, formats and checksums of the data.
